# CSE-17--SEM-2: NeuroPulse BCI, Offline GPS Tracker & Nexus Hub

Welcome to the **CSE 17 (Semester 2)** showcase repository by **Anurag Singh Chauhan**.

---

### 🌟 Featured Highlights

1. **🧠 NeuroPulse BCI (Brain-Computer Interface)**:
   - In-browser BCI simulator with 16-channel EEG waveforms.
   - Authentic P300 Thought-Speller Matrix for thought-to-text typing.
   - Real-time Web Audio API binaural beats (Alpha, Gamma, Theta, Delta) for neuro-entrainment.
   - Telekinetic Neuro-Drone flight simulator driven by attention and motor-imagery (C3/C4 suppression).
   - NASA TLX Cognitive Radar & Fatigue Index.
   - Biomedical multi-channel CSV dataset export.

2. **🚆 Offline Train GPS Tracker (Web PWA + Native Android Kotlin)**:
   - 100% offline satellite GPS speed and location tracker working with zero cellular network or Wi-Fi in Airplane Mode.
   - Dark OLED cockpit speedometer HUD in km/h with radial gauge arc.
   - Haversine distance accumulation and stationary drift jitter filtering.
   - Dual offline map system: Cache API route tile pre-downloader + HTML5 Canvas vector track plotter.
   - Native Android Kotlin project with background `ForegroundService` and persistent lockscreen notification.

3. **🏭 AeroPulse APCS**:
   - Modern Industrial Air Pollution Control System SCADA simulation dashboard.
   - 5-stage sequential flue gas abatement train (Cyclone, ESP/Baghouse, Wet Scrubber, Activated Carbon, ID Fan Stack).

4. **🎓 Semester 2 Coursework & Experiments**:
   - Comprehensive lab experiments, HTML/CSS/JS exercises, and React components.

## 🚀 Running the Project Locally

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Local Development Server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173`.

3. **Run Production Build:**
   ```bash
   npm run build
   ```
